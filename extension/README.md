# Clawd

VS Code extension for Clawd.

## Commands

- `clawd: Ask Mesh`
- `clawd: Ask Mesh about Selection`
- `clawd: Show Mesh Status`
- `clawd: Open Mesh`
- `clawd: Show Output`

## Requirements

Visual Studio Code 1.96.0 or newer.

## Extension Settings

- `clawd.meshUrl`: Mesh endpoint
- `clawd.meshModel`: Mesh model id
