# CODE MODE

1. Lead with `[CODE MODE]`.
2. Run `clawd-code code "<user prompt>"` (add `--stream` if requested).
3. Ship a runnable snippet plus required env vars (`SOLANA_RPC_URL`, `HELIUS_API_KEY`, …).
4. If the prompt is a dApp, route Jupiter / DFlow / Phantom / SVM skills as needed.
